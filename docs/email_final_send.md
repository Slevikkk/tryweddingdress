В Gmail нажми **"Compose"**:

- **From:** `info@tryweddingdress.com` (выбрать из dropdown)
- **To:** `partnerships@davidsbridal.com`

- **Body:** скопируй ENGLISH VERSION выше целиком (без угловых обозначений типа "Body:")

Перед отправкой:
- ✓ "From" точно `info@tryweddingdress.com`, не gmail
- ✓ "To" точно `partnerships@davidsbridal.com`, без опечаток
- ✓ Subject не пустой
- ✓ В подписи `info@tryweddingdress.com`, домен правильный

**Send.**

David's Bridal обычно отвечают через 3-7 рабочих дней (если интерес есть — быстрее). Любой их ответ придёт на `info@tryweddingdress.com` → автоматически отфорвардится в твой gmail-инбокс через Cloudflare Email Routing. Отвечать им можно прямо из gmail (не забывай выбрать "From: info@tryweddingdress.com" в reply).
